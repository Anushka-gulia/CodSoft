#  Task 1 - Titanic Survival Prediction

This project is part of my **Data Science Internship at CodSoft**, where I built a machine learning model to predict whether a passenger on the Titanic would survive or not.

---

##  Objective

To develop a logistic regression model using the Titanic dataset that classifies passengers as "Survived" or "Not Survived" based on features such as age, sex, class, fare, and port of embarkation.

---

## Dataset

- Source: [Kaggle - Titanic Dataset](https://www.kaggle.com/datasets/yasserh/titanic-dataset)
- File used: `titanic-dataset.csv`

---

##  Technologies Used

- **Python**
- **Pandas** for data manipulation
- **NumPy** for numerical operations
- **Matplotlib & Seaborn** (optional for visualization)
- **Scikit-learn** for machine learning model development

---

##  Workflow

1. Load dataset with Pandas
2. Handle missing values and encode categorical features
3. Select important features for prediction
4. Train a Logistic Regression model
5. Predict survival on test data
6. Evaluate using accuracy and confusion matrix

---
